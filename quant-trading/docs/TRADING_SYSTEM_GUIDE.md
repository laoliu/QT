## 1. 系统总览

系统由多个子系统协作完成「选股 → 下单 → 监控 → 止盈止损」全流程：

```
┌────────────────────────────────────────────────────────────────┐
│                    自动交易调度器 (每日)                          │
│  07:30 筛选 ──→ 09:31 下单 ──→ 条件单自动创建                    │
└───────┬───────────────┬──────────────────┬─────────────────────┘
        │               │                  │
  ┌─────▼─────┐  ┌──────▼──────┐  ┌───────▼────────┐
  │ 策略适配度 │  │ 推荐引擎    │  │ 条件单监控      │
  │ 全局排名   │  │ 8维评分     │  │ 每30秒检查      │

  └─────┬─────┘  └──────┬──────┘  └───────┬────────┘

  ┌─────▼─────┐  ┌──────▼──────┐  ┌───────▼────────┐
```

## 2. 自动交易调度器

### 工作流

每个**交易日**自动执行（非交易日跳过）：

| 时间 | 阶段 | 动作 |
|------|------|------|
| **07:30** | 🔍 筛选 | 从适配度排名取Top策略 → 全市场选股 → 生成推荐 |
| **09:31** | 🚀 执行 | 按推荐方案提交订单 + 自动创建条件单 |
| **周日 18:00** | 🎯 重优化 | 重新跑组合优化（可选） |

### 启动后自动补课

如果系统在计划时间之后启动（如 08:00 启动但筛选设定在 07:30），会自动检测并补跑错过的阶段。

### 运行模式

| 模式 | 说明 |
|------|------|
| **试运行 (dryRun=true)** | 走完全流程但不真实下单，只模拟计划 |
| **实盘 (dryRun=false)** | 真实提交订单到 QMT |

### 策略选择优先级

```
1. 用户手动指定策略 (config.strategies 非空)
   ↓ 为空时
2. 从策略适配度全局排名取 Top N (useFitnessStrategies=true)
   ↓ 查询失败时
3. 使用全量策略（慢）
```

## 3. 策略体系

### 筛选策略（投资规划器）

用于每日选股阶段，评分维度如下：

| 策略 | 名称 | 评分维度 | 持仓周期 |
|------|------|---------|---------|
| **mixed** | 混合策略 | 动量 + 价值 + 成长 | 20天 |
| **momentum** | 趋势动量 | 涨幅、换手率、成交额 | 10天 |
| **value** | 价值投资 | PE、PB、市值 | 90天 |
| **growth** | 成长投资 | 成长PE + 正向动能 | 60天 |
| **swing** | 波段交易 | 振幅、回调机会 | 15天 |
| **auto** | 自动（全维度） | 动量+价值+成长+波段 | 视情况 |

#### 各维度打分规则

**动量维度** (momentum/mixed/auto):
- 涨幅 >2%: +涨幅×1.0（最多 +10）
- 换手率 2-8%: +4（健康换手）
- 成交额 >5亿: +3（活跃交易）
- 换手率 >15%: 扣分（过热）

**价值维度** (value/mixed/auto):
- PE 5-20: +(20-PE)×0.5（低估加分）
- PB <2: +(2-PB)×3（低PB加分）
- 市值 >100亿: +2（大盘稳定）

**成长维度** (growth/mixed/auto):
- PE 20-50 且涨幅为正: +3
- 成交额 >3亿: +1

**波段维度** (swing/auto, 不含 mixed):
- 振幅 >3%: 加分
- 跌幅 -5% ~ -1%: 回调机会加分

### 技术指标策略（回测引擎）

用于策略适配度分析和组合优化：

| 策略ID | 名称 | 类型 |
|--------|------|------|
| `macd` | MACD 金叉/死叉 | 趋势跟踪 |
| `kdj` | KDJ 超买超卖 | 震荡指标 |
| `bollinger` | 布林带突破 | 波动率 |
| `mean_reversion` | 均值回归 | 反转 |
| `turtle` | 海龟突破 | 趋势跟踪 |
| `grid` | 网格交易 | 区间交易 |
| `multi_factor` | 多因子 | 综合 |
| `auction` | 竞价分析 | 开盘策略 |

这些策略可以**组合使用**（投票/加权/门控），详见[第6节](#6-组合优化系统)。

## 4. 每只股票的策略匹配

系统通过两层机制实现"因股施策"。

### 第一层：股票画像

`stock_profiler.py` 分析每只股票的特征：

| 维度 | 分类标准 |
|------|---------|
| **波动率** | 年化 <25% = 低, 25-50% = 中, >50% = 高 |
| **趋势** | MA20 > MA60 且价格在上 = 上涨; 反之 = 下跌; 否则 = 震荡 |
| **市值** | <50亿 = 微, <200亿 = 小, <1000亿 = 中, ≥1000亿 = 大 |
| **流动性** | 换手率 <1% = 低, 1-5% = 中, >5% = 高 |
| **动量** | 20日收益 >3% = 正, <-3% = 负, 否则 = 中性 |
| **量能趋势** | 5日/20日成交量比 <0.8 = 缩量, >1.5 = 放量, 否则 = 正常 |

### 第二层：策略路由

`strategy_router.py` 根据画像匹配最佳策略组合：

| 股票画像 | 推荐组合 | 组合方式 | 理由 |
|---------|---------|---------|------|
| 高波动 + 上涨 | MACD + KDJ | 投票(≥2) | 动量确认减少假信号 |
| 高波动 + 震荡 | 布林带 + 均值回归 | 门控 | 均值回归 + 布林带过滤 |
| 低波动 + 上涨 | 海龟 + MACD | 级联 | 趋势跟踪 |
| 低波动 + 震荡 | 网格交易 | 单策略 | 区间高抛低吸 |
| 中波动 + 上涨 + 大盘 | MACD + KDJ + 多因子 | 投票(≥2) | 三因子确认 |
| 中波动 + 上涨 + 小盘 | KDJ + 竞价 | 投票(≥1) | 小盘动量 |
| 中波动 + 震荡 | MACD + KDJ + 网格 | 投票(≥2) | 网格 + 均线过滤 |
| **任何下跌趋势** | MACD+KDJ+布林带+均值回归 | 投票(≥3/4) | **保守优先，风控第一** |
| 兜底默认 | MACD + KDJ | 投票(≥2) | 安全默认 |

宏观环境修正：在经济衰退/滞涨时期，自动提高投票门槛，偏向保守组合。

## 5. 策略适配度分析

### 分析流程

1. 选择股票池（沪深300/500/1000/全A）
2. 逐策略 × 逐股票 跑 5 年回测
3. 计算综合评分 → 个股排名 + 全局排名

### 综合评分公式

```
score = 总收益 × 1.0
      + 年化收益 × 0.35
      + 夏普比率 × 12
      + 胜率 × 0.28
      + min(盈亏比, 4) × 4
      − 最大回撤 × 0.85
      + min(交易次数, 120) × 0.03
```

### 产出两张表

**个股策略排名** (`stock_strategy_fitness`):
- 每只股票的策略排名（rank=1 是该股票最优策略）
- 包含所有回测指标

**全局策略排名** (`global_strategy_ranking`):
- 每个策略在全部股票上的总分、平均分、覆盖股票数
- rank=1 是全局最优策略

### 与自动交易的联动

自动交易调度器默认开启 `useFitnessStrategies`：
- 每天筛选时自动查询全局排名 Top 6 策略
- 只用这些策略做选股（快速 + 精准）
- 比固定用"混合策略"更有针对性

### 池回测增幅

如果某只股票同时出现在强势策略池回测中，其适配度评分会获得最高 20% 的增幅。

## 6. 组合优化系统

### 目的

为每只股票找到**最佳策略组合 + 最优参数**，生成交易计划。

### 流程

1. **读取适配度数据** — 取每只股票的 Top-K 策略（默认 K=5）
2. **生成组合排列** — 两两 + 三三组合 × 3 种组合方式
3. **两阶段网格搜索** — 粗搜（5步）→ 精搜（10步，围绕前3名参数）
4. **回测评分** — 含佣金/印花税/滑点的真实模拟
5. **保存最优结果** — 每只股票保存最佳组合 + 交易计划

### 三种组合方式

| 方式 | 机制 | 适用场景 |
|------|------|---------|
| **投票 (voting)** | 多数策略同意才交易（≥⌈n/2⌉） | 高确定性，减少假信号 |
| **加权 (weighted)** | 策略等权打分，总分≥0.6 则交易 | 平衡灵敏度和准确性 |
| **门控 (gated)** | 主策略发信号 + ≥1个确认策略 | 主次分明 |

### 交易计划输出

每只股票的优化结果包含完整交易计划：

```json
{
  "buyZones": [
    { "priceLevel": 25.5, "type": "BB下轨支撑", "strength": 0.8 },
    { "priceLevel": 24.8, "type": "MA20回调", "strength": 0.7 },
    { "priceLevel": 23.2, "type": "60日低点", "strength": 0.6 }
  ],
  "sellZones": [
    { "priceLevel": 28.5, "type": "BB上轨", "strength": 0.7 },
    { "priceLevel": 30.2, "type": "60日高点", "strength": 0.6 }
  ],
  "stopLoss": { "price": 22.5, "pctFromEntry": 5.0 },
  "takeProfitTiers": [
    { "targetPct": 10, "sellPortion": 0.3 },
    { "targetPct": 20, "sellPortion": 0.5 },
    { "targetPct": 30, "sellPortion": 1.0 }
  ],
  "positionSizing": {
    "method": "risk_pct",
    "initialPct": 5,
    "maxPct": 10
  }
}
```

### 仓位建议 (positionSizing)

基于夏普比率自动推荐仓位大小：

| 夏普比率 | 初始仓位 | 最大仓位 |
|---------|---------|---------|
| > 1.5 | 8% | 15% |
| 0.5 ~ 1.5 | 5% | 10% |
| < 0.5 | 3% | 8% |

## 7. 条件单监控系统

### 概述

条件单系统持续监控持仓/观察股票，在满足条件时自动执行交易。

### 支持的条件单类型

| 类型 | 名称 | 触发条件 | 动作 |
|------|------|---------|------|
| `stop_loss` | 止损 | 价格跌破止损价 | 卖出 |
| `take_profit` | 止盈 | 价格涨到目标价 | 卖出 |
| `staged_tp` | 分批止盈 | 分阶段达到不同目标 | 分批卖出 |
| `trailing_stop` | 跟踪止损 | 从最高点回撤N% | 卖出 |
| `trailing_atr` | ATR跟踪 | ATR动态止损 | 卖出 |
| `trailing_tp` | 跟踪止盈 | 动态止盈 | 卖出 |
| `indicator_stop` | 指标止损 | 技术指标信号 | 卖出 |
| `swing_grid` | 波段网格 | 价格触及网格线 | 买入/卖出 |

### 检查机制

- **实时检查**: 收到 QMT tick 数据时立即检查（stop_loss, take_profit, trailing_stop, swing_grid）
- **定期轮询**: 每 **30秒** 轮询所有活跃条件单，获取最新报价检查
- **手动检查**: UI 页面支持手动点击"立即检查"

### 自动推荐买卖股数

创建条件单时自动计算合理股数：

**买入区间**:
- 按各买入区间的支撑强度 (strength) 加权分配
- 总买入额度 ≈ 1× 初始持仓量，按强度比例分配
- 每个区间最少 100 股（A股整手），100 股取整

**卖出区间**:
- 总量 = 当前持仓量，按卖出区间从低到高分配
- 按强度比例分配，最后一个区间清仓全部剩余
- 每级最少保留 100 股给下一级

**加仓/减仓规则**:
- 加仓量 = 下跌幅度 × 持仓量，最少 100 股
- 减仓量 = 上涨幅度 × 持仓量，最少 100 股

### 限制

- 最多 **100 个** 活跃条件单
- 触发后的条件单 **2 个交易日** 后自动清理
- 触发历史保存到 `conditional-orders-history.json`

## 8. 自动持仓量计算

### 前端（批量监控对话框）

默认总资金 ¥1,000,000，支持三种分配方式：

| 方式 | 逻辑 |
|------|------|
| **智能推荐** (默认) | 夏普比率 → 仓位% × 置信度 → 资金 ÷ 价格 → 100股取整 |
| **按评分加权** | 评分占比 × 总资金 ÷ 价格 → 100股取整 |
| **等额分配** | 总资金 ÷ 股票数 ÷ 价格 → 100股取整 |

#### 智能推荐公式

```
仓位% = 夏普 > 1.5 → 8%, 夏普 0.5~1.5 → 5%, 夏普 < 0.5 → 3%
置信度 = min(夏普×0.2, 0.4) + min((胜率-45)/55×0.3, 0.3) + min(评分/100×0.3, 0.3)
预算 = 总资金 × 仓位% × 置信度
股数 = floor(预算 / 价格 / 100) × 100，最少 100 股
```

### 后端（兜底）

如果前端没传 quantity，后端从优化结果的 `positionSizing` 自动推导：

```
预算 = 默认资金(¥1,000,000) × initialPct% × confidence
股数 = max(100, floor(预算 / 价格 / 100) × 100)
```

## 10. 日常运行流程

### 工作日自动流程

```
07:30  ┌─ 策略适配度查询 → 取 Top 6 策略
       ├─ 多轮选股（新浪/AkShare/腾讯） → 候选股
       ├─ 回测验证 → 淘汰劣股
       └─ 推荐引擎 → 8维评分 + 资金分配 → 待执行推荐

09:31  ┌─ 按推荐方案下单（试运行/实盘）
       ├─ 自动创建条件单（止损/止盈/跟踪）
       └─ 通知结果

全天    ┌─ 条件单每 30 秒检查一次
       ├─ 实时 tick 检查止损/止盈
       └─ 突破监控持续运行

14:50  └─ 尾盘 MA 检查（突破监控的 EOD 退出）

15:30  └─ 日报生成（持仓盈亏、市场概况）
```

### 手动操作

| 操作 | 入口 | 说明 |
|------|------|------|
| 手动筛选 | 自动交易页 → 🔍 手动筛选 | 立即执行选股流程 |
| 手动执行 | 自动交易页 → 🚀 手动执行 | 提交待执行推荐 |
| 紧急停止 | 自动交易页 → ⏹️ 紧急停止 | 立即禁用调度器 |
| 批量监控 | 组合优化页 → 📡 批量监控 | 为选中股票创建条件单 |
| 删除条件单 | 条件单页 → 🗑️ 删除 | 删除单个或整组条件单 |
| 立即检查 | 条件单页 → 手动检查 | 立即检查所有条件单 |

### 重要注意事项

1. **试运行模式**默认开启，不会真实下单。确认选股效果后再关闭
2. **QMT 连接**是实盘交易的前提，未连接时订单无法提交
3. **条件单最多 100 个**，建议定期清理已触发的旧条件单
4. **策略适配度分析**建议定期重跑（每月或市场风格切换时）
5. **组合优化**支持周末自动重跑（`comboReoptEnabled`）
