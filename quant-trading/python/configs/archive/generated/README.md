# generated configs archive

本目录用于存放一次性生成、随机后缀命名、且当前仓库内无直接引用的历史配置文件。

归档原则：

- 优先归档 `configs/` 根目录下无明确长期归属的临时/一次性配置
- 迁移前先检查 `scripts/`、`src/`、`tests/`、`docs/` 中是否存在直接文件名引用
- 仅处理低风险文件；正式长期使用配置仍应保留在 `configs/backtest/`、`configs/paper/`、`configs/data/`、`configs/universe/` 等目录
