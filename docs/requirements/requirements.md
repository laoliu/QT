## 二、功能需求 (FR)

### FR-1 多账户管理（对应 G1）

**优先级：P0**

| 子项 | 描述 |
|------|------|
| FR-1.1 | 支持配置多个交易账户（同一券商多账户 / 不同券商混合），每个账户独立持仓、资金、订单 |
| FR-1.2 | 账户间资金/持仓隔离，互不影响 |
| FR-1.3 | 提供账户切换命令/工具，当前上下文绑定到指定账户 |
| FR-1.4 | 聚合视图：跨账户汇总持仓、总资产、总盈亏 |
| FR-1.5 | 每个账户可独立配置风控参数 |

### FR-2 富途券商适配器（对应 G2）

**优先级：P0**

| 子项 | 描述 |
|------|------|
| FR-2.1 | 实现 `FutuBrokerAdapter`，遵循已有 `IBrokerAdapter` 接口 |
| FR-2.2 | 通过 Futu OpenD 网关连接，支持配置中已有的 host/port/password/account 字段 |
| FR-2.3 | 支持 A股/港股 市价单、限价单 |
| FR-2.4 | 实时推送持仓和订单状态变更 |
| FR-2.5 | 集成现有17条风控规则 |

### FR-3 批量下单 / 篮子交易（对应 G8）

**优先级：P0**

| 子项 | 描述 |
|------|------|
| FR-3.1 | 支持一次性提交多个股票的买入/卖出订单（篮子单） |
| FR-3.2 | 篮子单支持按金额/按股数/按权重三种模式 |
| FR-3.3 | 提交前展示预览：各标的买入数量、预估金额、佣金预估 |
| FR-3.4 | 每笔子单独立经过风控门禁检查 |
| FR-3.5 | 篮子单整体状态追踪（全部成交/部分成交/部分失败） |
| FR-3.6 | 与组合再平衡联动：再平衡计划可直接生成篮子单执行 |

### FR-4 交易绩效报告（对应 G3）

**优先级：P1**

| 子项 | 描述 |
|------|------|
| FR-4.1 | 生成可导出的绩效报告（HTML/PDF），包含：总收益、年化收益、最大回撤、夏普/索提诺比率、胜率、盈亏比 |
| FR-4.2 | 按时间维度（日/周/月/季/年）的收益曲线和回撤曲线 |
| FR-4.3 | 按行业/个股/策略的收益归因分解 |
| FR-4.4 | 交易行为统计：平均持仓天数、换手率、最大单笔盈亏 |
| FR-4.5 | 与基准指数（沪深300/中证500）的对比分析 |

### FR-5 资金曲线交互式分析（对应 G4）

**优先级：P1**

| 子项 | 描述 |
|------|------|
| FR-5.1 | Web页面提供可缩放、可拖拽的资金曲线图 |

## 四、验收标准

### AC-1 多账户管理

- [ ] 可配置至少2个不同券商账户，启动后各自独立初始化
- [ ] 在账户A下单不影响账户B的持仓和资金
- [ ] 聚合视图正确汇总所有账户的总资产
- [ ] 切换账户时有明确的确认提示

### AC-2 富途券商适配器

- [ ] 通过 Futu OpenD 成功连接并获取账户信息
- [ ] 提交市价单/限价单后能在富途客户端看到对应挂单
- [ ] 订单状态变更（成交/撤单）在3秒内同步到系统
- [ ] 断线后30秒内自动重连
- [ ] 所有17条风控规则在富途下单前正确执行

### AC-3 批量下单

- [ ] 一次提交10只股票的买入篮子单，全部正确拆分为独立子单
- [ ] 按权重模式：给定总金额100万和5只股票各20%，计算出正确的买入数量（A股100股整数倍）
- [ ] 风控拒绝某只股票时，其余股票正常下单，被拒股票返回拒绝原因
- [ ] 再平衡计划一键生成篮子单并执行

### AC-4 绩效报告

- [ ] 生成的HTML报告包含全部指标（收益/回撤/夏普/胜率/盈亏比）
- [ ] 月度收益曲线与真实交易记录一致
- [ ] 行业归因之和等于组合总收益
- [ ] 报告可在浏览器中正确渲染

### AC-5 数据导出

- [ ] 导出的CSV文件用Excel打开中文不乱码
- [ ] 交易记录导出包含：时间、代码、名称、方向、价格、数量、金额、佣金、盈亏
- [ ] 回测结果导出包含逐笔交易明细和汇总指标

### AC-6 策略实盘 vs 回测对比

- [ ] 同一策略同一时段的实盘与回测收益曲线可叠加显示
- [ ] 偏离度超过设定阈值（如20%）时触发告警
- [ ] 滑点统计正确反映实际成交价与信号价的差异

## 六、边界条件和开放问题

### 边界条件

| # | 条件 | 处理方式 |
|---|------|---------|
| B1 | 篮子单中某只股票停牌 | 跳过该标的，其余正常执行，返回跳过原因 |
| B2 | 篮子单总金额超过可用资金 | 提交前校验，拒绝整个篮子并提示差额 |
| B3 | 多账户聚合时某账户离线 | 聚合视图标注该账户为"离线"，使用最后缓存数据 |
| B4 | 富途OpenD意外断开 | 自动重连3次，失败后暂停该账户下单并告警 |
| B5 | 导出数据量超过Excel行数限制（104万行） | 自动分片为多个文件 |
| B6 | 策略实盘与回测时间段不完全对齐 | 取交集时间段对比，标注缺失区间 |
| B7 | 跨市场篮子单（同时含A股和港股） | 按市场拆分为多个子篮子，各自走对应券商通道 |
| B8 | 账户切换时有未完成订单 | 阻止切换并提示用户先处理未完成订单 |

### 开放问题

| # | 问题 | 影响范围 | 建议决策时间 |
|---|------|---------|------------|
| Q1 | 多账户数据存储方案：单文件分区 vs 多文件隔离？ | FR-1 架构设计 | 设计阶段 |
| Q2 | 富途 OpenD 是否支持用户当前系统（macOS）？需确认环境要求 | FR-2 可行性 | 开发前 |
| Q3 | 篮子单是否需要支持"撤销整个篮子"（未成交子单全部撤回）？ | FR-3 功能范围 | 设计阶段 |
| Q4 | 绩效报告是否需要支持自定义模板？还是固定格式即可？ | FR-4 复杂度 | 设计阶段 |
| Q5 | 数据导出是否需要支持定时自动导出（如每月自动生成月报CSV）？ | FR-7 功能范围 | 设计阶段 |
| Q6 | 策略衰减告警阈值默认值如何设定？是否需要按策略类型差异化？ | FR-8 参数设计 | 开发阶段 |
| Q7 | 现有 `orders-paper.json` / `orders-live.json` 单文件存储在多账户场景下是否有性能瓶颈？是否需要迁移到SQLite？ | FR-1 + 整体架构 | 设计阶段 |
| Q8 | RemoteQMT 与富途是否需要支持同时在线（多券商并行交易）？ | FR-1 + FR-2 | 设计阶段 |
